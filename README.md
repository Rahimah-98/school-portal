# School Portal is a multi-page student management system:

This project allows students to enroll, view profiles, explore courses, and send messages to the school.

This project focuses heavily on JavaScript DOM manipulation, dynamic rendering, and event-driven UI updates.

## Features
- Student enrollment system with validation
- Dynamic student profile dashboard
- Interactive course listing with filtering and details view
- Contact form with validation and feedback messages
- Fully dynamic UI without page reloads


## Key learning concepts:
- By working this project I improved my undrestanding of DOM, Event handling events by (addEventListener()), dataset, Working with arrays of objects, Rendering UI using loops
